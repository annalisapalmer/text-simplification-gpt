# Text Simplification via Machine Translation and Language Models

This project explores methods for simplifying complex English text into simpler versions using rule-based approaches, heuristic synonym replacement, and large language models like GPT. It was inspired by academic work in semantic simplification, paraphrase generation, and neural translation.

> **Disclaimer**: This repo reflects my independent exploration and understanding of text simplification methods. No course-assigned code or proprietary tools are shared in accordance with academic integrity policies.

## Goals

- Understand linguistic complexity and its quantification (e.g., Flesch–Kincaid)
- Build rule-based simplifiers using WordNet and word frequency heuristics
- Explore zero-shot and few-shot simplification using GPT-3/4 APIs
- Compare simplifications using readability scores and semantic similarity

## Technologies Used

- Python
- OpenAI API
- NLTK (WordNet)
- Scikit-learn (cosine similarity)
- Textstat
